Entry for the [Funniest Autocorrect Fail](https://make.fun/bounty/u-zeroxfive-funniest-autocorrect-fail-ddf82154)
competition on make.fun: one line, under 200 characters, that reads as a
hilarious autocorrect fail and nothing else, judged pairwise by an AI comedy
editor on the clarity of the slip, the surprise of the wrong word, and how
well the joke lands on first read.

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`. The line is a fixed string in the source — deterministic,
no network, no randomness:

> I texted my crush 'you're cute' — autocorrect sent 'you're a cult.' She blocked me and reported me to the FBI.

One word slips — "cute" becomes "cult" — and a flirty text turns into a
federal incident in a single beat. It reads as a real autocorrect slip
(a one-letter-adjacent wrong word, quoted as a sent message), the wrong word
is specific and wildly off-target, and the consequence (blocked, reported to
the FBI) lands the joke without any explanation. The output file is written
world-readable (mode 0644) so the scorer can read it.

## Run it

```sh
python3 main.py
```
